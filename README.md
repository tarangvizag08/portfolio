# Tarang Gupta — Portfolio

Personal portfolio website: about, research, projects, experience, leadership,
skills, gallery, achievements and a contact form.

## Tech stack

- **Framework:** Next.js 16 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS v4, shadcn/ui (Base UI)
- **Animation:** Motion, GSAP
- **Graphics:** OGL (WebGL), Three.js with React Three Fiber
- **Backend:** Next.js Route Handler for the contact form
- **Database:** PostgreSQL with Prisma
- **Email:** Resend
- **Validation:** Zod
- **Icons:** Lucide

## Components used

From [React Bits](https://reactbits.dev):

- AeroShards, Aurora — animated backgrounds
- BorderGlow, MagicBento — cards
- InfiniteSpiral — photo gallery
- ScrollFloat, SplitText, CountUp — text animations
- Dock, LineSidebar — navigation
- SpecularButton, GradualBlur — buttons and blur effects
